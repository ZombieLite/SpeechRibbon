# SpeechRibbon

SpeechRibbon использует локальные модели для транскрибации аудио и видео, определения языка, разделения речи по говорящим и перевода результата. Аудио и видео обрабатываются на устройстве. Дополнительная вкладка «ИИ» позволяет по вашей команде отправить текст транскрибации и инструкцию на настроенный вами сервер.

## Возможности

- Транскрибация аудио и видео с использованием локальных ИИ-моделей.
- Автоматическое определение языка речи.
- Разделение реплик по говорящим.
- Перевод транскрибации с разных языков на русский или английский.
- Экспорт результата в TXT, SRT и VTT.
- Обработка текста через OpenAI-совместимый Chat Completions API: свой адрес, ключ и модель.
- Редактируемый промпт, отмена запроса, копирование и сохранение ответа ИИ.

## Системные требования

- Windows 10/11 x64.
- Процессор с поддержкой AVX2 и не менее четырёх физических ядер.
- 8 ГБ оперативной памяти.

## Поддерживаемые форматы

- Аудио: WAV, MP3, FLAC, M4A, AAC, OGG, OGA, OPUS, WMA.
- Видео: MP4, M4V, MOV, MKV, WEBM, AVI, WMV.

## Как пользоваться

1. Скачайте и запустите SpeechRibbon.
2. Выберите аудио или видео.
3. По умолчанию приложение транскрибирует речь на исходном языке. При необходимости выберите перевод на русский или английский.
4. Запустите обработку.
5. Скопируйте результат или сохраните его в TXT, SRT либо VTT.

## Дополнительная обработка с ИИ

1. Откройте «Настройки ИИ», введите Base URL, API Key и точное название модели. Готовых адресов, ключей и моделей в программе нет.
2. «Проверить подключение» отправляет короткий тестовый запрос без транскрибации. Нажмите «Сохранить», чтобы применить настройки.
3. После получения транскрибации откройте вкладку «ИИ», отредактируйте промпт и нажмите «Отправить».
4. Для нового задания нажмите «Изменить промпт». «Вернуться к ответу» показывает прежний ответ без отправки запроса.

Настройки автоматически создаются при сохранении в `SpeechRibbon.settings.json` рядом с EXE. В этой версии ключ замаскирован на экране, но хранится в файле **без шифрования**. Не передавайте этот файл другим людям; он и его временные копии исключены из Git. Для обычной транскрибации подключение к серверу не требуется.

Запросы выполняются только после нажатия «Проверить подключение» или «Отправить». Во втором случае сервер получает полный текст и промпт, но не аудиофайл. Подробнее: [контракт подключения](docs/ai-api.md).

**Особенность 0.0.10:** клиент ИИ не проверяет подлинность сертификата HTTPS (аналог `curl -k`). Соединение шифруется, но подмена сервера не обнаруживается. Используйте только доверенную сеть и сервер. Настройки Windows не изменяются.

## Ограничения

- Не поддерживаются защищённые DRM, зашифрованные и повреждённые файлы.
- В музыкальных записях распознаётся только слышимая речь; отделение вокала от инструментов не выполняется.
- Разделение по говорящим, особенно при одновременной речи, может быть неточным.
- Совместимость конкретного сервера и качество ответа зависят от провайдера и выбранной модели. Ответ ИИ следует сверять с исходным текстом.
- Полный текст отправляется без автоматического разбиения: при превышении контекста модели запрос может быть отклонён. Пустой ответ, ошибка и отмена не заменяют предыдущий результат.
