# Подключение к ИИ

SpeechRibbon использует OpenAI-совместимый Chat Completions API. Сервер и модель выбирает пользователь; предустановленного провайдера нет.

## Запрос

Base URL дополняется `/chat/completions`. Для корневого адреса добавляется `/v1/chat/completions`. Готовый полный путь сохраняется. Ключ передаётся в заголовке Bearer, выбранная модель — в `model`; `messages` содержит инструкцию и полный текст транскрибации, `stream` равен `false`.

Проверка подключения отправляет короткую тестовую инструкцию без текста записи и не сохраняет настройки автоматически. Отправка задания выполняется только по кнопке «Отправить». Запуск приложения, сохранение настроек и смена вкладки сетевых запросов не вызывают.

Ответ читается из `choices[0].message.content`. Повреждённый или пустой ответ, ошибка, отмена либо прерывание лимитом модели не заменяют предыдущий результат. Поздний ответ не применяется после смены исходного документа. Автоматического разбиения длинного текста нет.

Ожидание проверки ограничено 30 секундами, обработки — 10 минутами. Поддерживаются HTTP и HTTPS. В версии 0.0.8 подлинность сертификата HTTPS не проверяется (аналог curl -k); переключателя нет, настройки Windows не меняются. Это допускает подмену сервера, несмотря на шифрование HTTPS. Перенаправления не выполняются. Ошибки показывают HTTP-код и JSON-пояснение (чтение до 16 КиБ, показ до 1200 символов); HTML и вложенные дампы входных данных не выводятся. Из пояснения удаляются известный ключ, полный промпт/транскрибация и их строки от 8 символов. Произвольные фрагменты или перефразированные данные серверного сообщения не всегда распознаются — проверяйте текст перед передачей другим людям. Ошибки на диск не записываются.

## Настройки

При нажатии «Сохранить» создаётся `SpeechRibbon.settings.json` рядом с внешним запускаемым EXE. Для обновления оставьте этот файл в папке с новой версией. Он не входит в дистрибутив и исключён из Git. Папка временно извлечённого runtime для хранения настроек не используется.

В первой версии ключ хранится открытым текстом, а маскирование действует только в интерфейсе. Файл содержит BaseUrl, ApiKey и Model. Не включайте его в архивы для публикации или отчёты об ошибках. Отмена редактирования не меняет сохранённые настройки; при отказе записи программа показывает ошибку.

## Проверки

Локальные автоматические проверки охватывают HTTP-обмен с тестовым сервером, полный длинный текст, ошибки и отмену, сохранение настроек, а также WPF-состояния редактора и ответа. Они не гарантируют совместимость любого стороннего сервера или достоверность ответа модели.
