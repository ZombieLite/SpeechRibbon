# Изменения

## 0.0.10

- Тёмная тема использует согласованные графитовые кнопки, вкладки и состояния списка; исправлены цвет ключа и курсоров ввода.
- Отправка и отмена ИИ перенесены наверх. Кнопка «Начать» доступна только на вкладке транскрибации.
- При ожидании ответа отображается прошедшее время; отмена сохраняет промпт и предыдущий ответ.
- Парные двойные звёздочки в ответе отображаются жирным шрифтом.
- Удалена отметка «Актуальная»: приложение не проверяет наличие обновлений.
- Проверены регрессия интерфейса, сборка и запуск точного EXE. Внешний сервер ИИ при проверках не использовался.

## 0.0.9

- Добавлен явный параметр max_tokens: 512 для проверки подключения и 8192 для обработки текста. Он предотвращает резервирование всего контекста сервером под ответ при отсутствии лимита.
- Текст транскрибации передаётся полностью. Вход вместе с резервом ответа должен помещаться в контекст выбранной модели.
- Регрессия воспроизводит отказ при отсутствии лимита и проверяет оба исправленных запроса. Поддержка параметра конкретным внешним сервером требует проверки; автоматического переключения на max_completion_tokens нет.

## 0.0.8

- Ошибки API показывают точный HTTP-код и ограниченное очищенное пояснение сервера; текст можно скопировать.
- Различаются ошибки DNS, соединения и TLS.
- Проверка подлинности сертификата отключена только для клиента ИИ, без переключателя и изменения Windows. Перенаправления запрещены. Это снижает защиту от подмены сервера.
- Адрес, ключ и модель по-прежнему задаются пользователем.
- Проверены локальный HTTP/HTTPS, обработка ошибок, интерфейс и запуск готового EXE. Совместимость конкретного внешнего сервера проверяется отдельно.

## 0.0.7

- Добавлена вкладка «ИИ» с подключением к настраиваемому Chat Completions API, проверкой подключения и сохранением настроек рядом с программой.
- Добавлены универсальный редактируемый промпт, поясняющая подсказка, отмена запроса и сохранение ответа. Промпт и ответ показываются по очереди, сохраняя доступное место.
- Вкладка «ИИ» появляется после сохранения настроек; отправка доступна после получения транскрибации.
- Выбор языка результата перенесён в компактный список в блоке файла. Поле пути и исходные функции транскрибации сохранены.
- Четыре значка управления окном заменены векторными фигурами, независимыми от значкового шрифта.
- Файл настроек и временные копии исключены из Git. В этой версии ключ хранится в файле без шифрования.

## 0.0.6

Предыдущая опубликованная версия локальной транскрибации. Её EXE сохранён в `dist`.
